# 武器附加屬性（隨機前綴／後綴）

依 es2_pal「武器附加屬性表」製作，套用在 `obj/area/obj/` 的 12 種一般武器：長劍、短劍、單刀、鬼頭刀、大劍（bastardsword、greatsword）、闊劍、彎刀、大刀、板斧、長槍、鐵鞭，以及匕首（`obj/area/obj/dagger.c`）、齊眉棍（`d/lee/obj/brow_staff.c`）、木杖（`custom/weapon/staff/long_staff.c`）、禪杖（`custom/weapon/staff/zenstaff.c`）和竹釣竿（`custom/weapon/whip/bamboo_fishing_rod.c`）。

## 規則

- 每把武器**產生時**擲一次（NPC 身上、地上產生都一樣）：普通 60%、只有前綴 30%、前綴＋後綴 10%。
- **商店販賣的武器一律是普通品**（使用者決定，2026-10-16）：商人交貨時改回普通武器
  （`feature/npc/vendor.c` 的 `plain_goods()`），名稱、價錢、能力都是原本的。當鋪轉賣的是玩家當掉的武器，照原樣保留。
  **必須有前綴才會有後綴。**
- 名稱為「前綴＋後綴＋武器種類」，原名改顯示成種類：劍類（長劍、短劍、大劍、闊劍）→「劍」，刀類（單刀、鬼頭刀、彎刀、大刀）→「刀」，匕首→「匕」，木杖→「杖」，齊眉棍→「棍」，禪杖→「禪杖」，斧→「斧」，槍→「槍」，鐵鞭→「鞭」，竹釣竿→「竿」。例如「黑鋼劍 (Long sword)」「精鋼火炎劍 (Short sword)」。英文名稱不變，用來分辨是哪一種。
- 整把名稱用同一個顏色：只有前綴就用前綴的顏色，有後綴就用後綴的顏色。沒有詞綴的武器維持原名、不上色。
- 種類依武器的 `wield_as` 判斷；個別武器可以用 `set("affix_short_name", ...)` 自己指定（鐵鞭、齊眉棍、禪杖、竹釣竿就是這樣）。
- 武器原本的特性會保留，詞綴加在上面（例如竹釣竿的捕魚技巧 +3）。
- 加成在這把武器的每一種用法（例如劍術、左手劍術）裝備時生效，卸下即消失。
- 每個修飾讓價值變成 1.5 倍（前綴＋後綴為 2.25 倍）。
- 結果記在武器的 `affix`（`([ "prefix": …, "suffix": … ])`）。家園儲物箱會照存，取出時原樣還原（普通武器也不會重擲）。
- 程式：`adm/daemons/enhanced.c` 的 `roll_affix()`、`apply_affix()`。`AFFIX_COLOR` 設為 0 可改成不上色。原本只在 NPC 身上強化的 `enhance_weapon()` 已不再使用。

## 竹釣竿

- 比生鐵釣竿弱的一般釣竿：軟鞭鞭法，傷害 6–24（生鐵釣竿 10–43），重 3500，價值 20 兩，特性只有捕魚技巧 +3。
- 五堂鎮鯉君渡口的兩名釣客各拿一支，產生時同樣擲詞綴。
