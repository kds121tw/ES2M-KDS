# 網頁版 zMUD 指令

使用者確認：2026-11-09（第一批全部做；第二批只做 `#gag`、`#color`）。

網頁輸入欄、觸發、計時器都能用這些指令；它們在瀏覽器裡執行，**不會送到遊戲**（`#if` 選中的、縮寫展開後的一般指令才會送）。
設定（縮寫、變數、隱藏、上色、觸發、計時器）都存在玩家自己的瀏覽器，可以在「觸發」視窗匯出／匯入。

程式：`web/zscript.js`（拆指令、運算式、變數與函數、快速移動）、`web/automation.js`（執行與各指令）、
`web/app.js`（角色狀態變數、畫面輸出經過 `processOutput` 處理隱藏與上色）。測試：`tests/test_automation_zscript.mjs`。

## 原本就有的

| 指令 | 說明 |
|---|---|
| `#wa 毫秒` | 等一下再送後面的指令（只寫 `#wa` 是 1 秒） |
| `#3 指令`、`#3 {指令;指令}` | 重複 3 次 |
| `#tr`、`#tr on`、`#tr off` | 開關全部觸發 |
| `#t+ 類別`、`#t- 類別` | 開關某一組觸發 |
| `#sh 文字` | 只在自己畫面顯示 |
| `#dis`、`#con` | 中斷連線／重新連線 |

## 第一批

| 指令 | 說明 | 例子 |
|---|---|---|
| `#if (條件) {成立} {不成立}` | 條件判斷，後面的 `{…}` 可省略 | `#if (@hp < 50) {eat dumpling}` |
| `#while (條件) {指令}` | 條件成立就一直做（每做完一次重新判斷） | `#while (@n < 3) {#add n 1}` |
| `#loop 次數 {指令}`、`#loop 起,迄 {指令}` | 重複；`%i`（或 `%repeatnum`）是第幾次；最多 99 次 | `#loop 1,3 {say %i}` |
| `#case 數字 {一} {二} …` | 執行第幾個區塊 | `#case %random(1,3) {n} {s} {e}` |
| `#abort` | 停止這串指令後面還沒做的部分 | |
| `#var 名稱 值`、`#var 名稱`、`#var` | 設定／顯示一個／列出全部變數；值有空白用 `{}` 括起來 | `#var target 野狗` |
| `#unvar 名稱` | 刪除變數 | |
| `@名稱` | 指令裡帶入變數；沒有這個變數時保留原文 | `kill @target` |
| `#math 名稱 運算式` | 計算後存進變數 | `#math half @qimax/2` |
| `#add 名稱 數字` | 加到變數上（沒寫數字是加 1） | `#add kills 1` |
| `#alias 名稱 {指令}`、`#alias 名稱`、`#alias` | 設定／顯示／列出縮寫；`%1`～`%9` 是後面的字、`%*` 是全部；沒用到 `%` 時後面的字接在最後；名稱不分大小寫 | `#alias kk {kill %1;perform %1}` |
| `#unalias 名稱` | 刪除縮寫 | |
| `#trigger {樣式} {指令} [類別]` | 新增觸發（`#tr {…} {…}` 也可以；`#tr` 單獨或 `on/off` 仍是開關） | `#trigger {^(%w)向你撲過來} {kill %1} 戰鬥` |
| `#untrigger {樣式}` | 刪除樣式相同的觸發 | |
| `#alarm 秒數 {指令}` | 幾秒後執行一次（重新整理或斷線就取消） | `#alarm 30 {eat dumpling}` |
| `#echo 文字` | 同 `#sh` | |
| `#beep` | 叫一聲提示音 | |
| `.3n2e` | 快速移動，等於 `n;n;n;e;e`；斜角用括號 `.2(ne)`；方向字 n s e w u d | |

### 角色狀態變數

`@hp` 形體、`@jing` 精、`@qi` 氣、`@shen` 神、`@food` 食物、`@water` 飲水、`@fatigue` 疲勞；
後面加 `max` 是最大值（`@hpmax`、`@qimax`…）；也可以寫 `@gin`、`@kee`、`@sen`。
數字來自右邊的角色狀態（背景狀態查詢每隔一會兒更新），不能用 `#var` 設定。

### 條件與運算式

- 比較：`=`（或 `==`）、`!=`（或 `<>`）、`>`、`<`、`>=`、`<=`。兩邊都是數字就照數字比，否則照文字比。
- 組合：`&`（或 `&&`）而且、`|`（或 `||`）或者、`!` 不是；括號分組。
- 計算：`+ - * /`，`%` 取餘數；除法取整數（同 zMUD）。
- 文字：有空白的用 `"雙引號"`；沒加引號、連在一起的字當成一段文字（觸發帶入的「測試 玩家」也算一段）。
- 成立的意思：不是 0、也不是空白。

### 函數

| 函數 | 結果 |
|---|---|
| `%len(文字)` | 字數 |
| `%random(n)`／`%random(a,b)` | 0～n／a～b 的整數亂數 |
| `%time` | 現在時間（時:分:秒） |
| `%left(文字,n)`、`%right(文字,n)` | 左邊／右邊 n 個字 |
| `%pos(找的字,文字)` | 在第幾個字（從 1 開始，找不到是 0） |
| `%eval(運算式)` | 計算結果 |
| `%if(條件,是,否)` | 條件成立給「是」，否則給「否」 |

## 第二批（這次做的兩個）

| 指令 | 說明 |
|---|---|
| `#gag {樣式}` | 之後符合樣式的整行不顯示（觸發照樣會比對） |
| 觸發指令裡單獨的 `#gag` | 隱藏觸發的那一行 |
| `#ungag {樣式}` | 取消隱藏 |
| `#color {樣式} 顏色` | 把符合樣式的文字上色；顏色：紅 綠 黃 藍 紫 青 白 灰 橘 粉紅，前面加「亮」更亮；英文 red green yellow blue magenta cyan white gray orange pink，前面加 hi 更亮 |
| `#uncolor {樣式}` | 取消上色 |

樣式寫法與觸發相同（`*`、`%w`、`^` 行首……）。限制：一行文字如果被拆成兩段傳來，前一段已經顯示，就只能隱藏或上色後一段。

## 寫法細節與保護

- 大括號 `{}`、小括號 `()`、雙引號裡的 `;` 不會拆開；要送出 `; { } @ %` 本身時前面加 `~`。
- `#if`、`#while`、`#loop` 的內容在**真正輪到它時**才展開，所以前面 `#var` 改的值，後面就讀得到。
- 保護沿用原本的規則：玩家輸入欄一次最多送 9 個指令（迴圈、縮寫展開的也算）；
  自動指令一秒超過 20 個全部暫停；輸入密碼、寫文章時不送。
- 另加：一串指令沒有 `#wa` 卻處理超過 2000 步（例如停不下來的 `#while`、互相呼叫的縮寫）就停止並提示。
- 運算式由網頁自己逐字解析，不會把文字當成程式執行，貼來的觸發不會變成惡意程式。

## 管理

「觸發」視窗新增「縮寫與變數」分頁：列出縮寫、變數、隱藏、上色，可以刪除；新增用指令。
