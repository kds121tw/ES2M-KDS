# 玩家版天朝圖鑑（討論稿）

狀態：**已製作（2026-10-23）**。

## 一、目標

做一份給玩家看的天朝圖鑑，只列出**遊戲裡已經實裝、玩家走得到**的內容：
地圖、NPC、門派、技能、裝備與物品。

- 不公開公式：升級門檻、傷害計算、學成點數等都不寫。
- 技能會說明「練了會增加哪些屬性」，例如「修練有成時，膂力與根骨會隨之增長」，但不寫數字。
- 現有的巫師版圖鑑（`docs/catalog/es2_catalog.html`，含公式、檔案路徑、未實裝內容）保留不動，兩份分開。

## 二、「以地圖為基礎」怎麼判斷

從玩家出生的雪亭鎮客棧大堂出發，沿著房間出口一路往外走，**走得到的房間才算實裝**：

| 內容 | 算「實裝」的條件 |
|---|---|
| 房間、區域 | 從客棧大堂沿出口（含 climb、search 等特殊進出方式）走得到 |
| NPC | 被放在走得到的房間裡 |
| 裝備、物品 | 走得到的房間地上擺的、走得到的 NPC 身上穿戴或攜帶的、走得到的商店賣的 |
| 技能 | 走得到的師父教的、走得到的書能讀的，或上面列出的裝備會用到的武功 |
| 門派 | 掌門或師父是走得到的 NPC |

自動排除的內容：
- 還沒接上地圖的區域（做到一半的地方）
- 巫師工作室、家園等系統房間
- 沒被放在任何房間的 NPC、沒有任何取得方式的物品

做不到自動判斷的：NPC 死後才掉落、任務獎勵等寫在劇情程式裡的物品。這類東西**待確認**（見第六節）。

## 三、各分頁內容

### 地圖
- 依區域顯示房間格子圖（沿用巫師版圖鑑的排版），點房間看描述、出口、這裡有哪些 NPC 與物品。

### NPC
- 名稱、外觀描述、出沒地點（點了跳到地圖）。
- 販賣的商品、可以拜師或學的武功（如果有）。
- 戰力數值（等級、技能等級、屬性）：**待確認**。

### 門派
- 門派名稱、所在地、掌門與師父、門下武功。
- 入門條件：**待確認**。

### 技能
- 名稱、分類（武學、法術、知識……）、說明文字。
- 修練會增長的屬性（只寫屬性名稱，不寫數字）。
- 去哪裡學：師父、門派或書籍。
- 不寫：升級門檻、學成點數、等級上限的計算方式。

### 裝備與物品
- 名稱、外觀描述、種類（刀、劍、衣服、戒指……）、取得地點或來源 NPC、價格。
- 能力數值（傷害力、防禦力、屬性加成）：**待確認**。

### 文字規則
比照遊戲內的敘述規則（`CLAUDE.md`）：
- 不寫等級數字，例如不寫「需要三十級」，改寫成「火候未到不能學」這類說法。
- 不寫指令名稱。
- 不顯示程式路徑、英文代碼。

## 四、放在哪裡、怎麼更新

- **放在遊戲網站上**（建議）：做成 `https://161-118-234-100.sslip.io/codex.html`，遊戲畫面左側選單加一個「圖鑑」連結，玩家不用登入也能看。
- **自動更新**（建議）：主機每次執行 `update.sh` 時自動重新產生，內容永遠跟遊戲一致，不用另外手動同步。
- 產生程式沿用巫師版的 `tools/build_codex.py`，加一個「玩家版」模式，分析程式碼只寫一份。

## 六、已確認事項（2026-10-23）

1. 放在遊戲網站上：`/codex.html`，遊戲畫面左側選單加「圖鑑」。
2. 要特殊動作才進得去的房間照常顯示，但不畫連線、不說明怎麼進去。
3. 裝備數值要顯示（傷害、防禦、屬性加成）。
4. NPC 戰力不顯示（不列等級、技能、屬性）。
5. 門派入門條件要寫：文字放在 `docs/catalog/玩家圖鑑_門派.md`，可直接修改。
6. 掉落物與任務獎勵不列；解謎才學得到的武功、以及會傳授解謎武功的 NPC 的傳授清單也不列。
7. 每次執行 `update.sh` 自動重新產生（`web/codex.html` 不放進 git）。

## 七、製作說明

- 產生程式：`tools/build_player_codex.py`（共用 `tools/build_codex.py` 的分析，巫師版輸出不變）。
- 網頁樣板：`tools/codex_player_template.html`。
- 網頁裡的房間、人物、物品、技能都改用流水編號，不含檔案路徑。
- 技能說明取自技能檔開頭的說明，自動拿掉英文與程式用語；沒有說明的基本技能只列分類與增長屬性。
- 技能增長的屬性：基本技能依 `feature/char/skill.c` 的對應表，武功依技能檔裡提升屬性、精氣神上限的程式。

## 八、技能細節（使用者指示，2026-10-23）

技能分頁公開更多細節，**唯獨不寫經驗值（累積點數）的計算公式**：
1. 練成幾級：自動讀技能檔的學成等級，沒有指定的是 1 級。
2. 精氣神成長：寫在 `docs/catalog/玩家圖鑑_技能.md`。
3. 屬性成長：同上；基本技能依 `ATTR_GROWTH` 自動寫「每練到 5 的倍數有機會提升某屬性 1 點」。
4. 法術、咒術：各道法術的學會等級、耗神、效果、傷害百分比，寫在 `docs/catalog/玩家圖鑑_法術.md`。
5. 隱藏門檻也公開（例如瘋虎功 90 級衝關的實戰經驗門檻）。
6. 之後改武功時一起更新這兩份表格（已寫進 `CLAUDE.md`）。

## 九、第三輪修改（使用者指示，2026-10-24）

1. 武功列出招式（技能檔 `moves`，含幾級起可用），絕招、殺招與內功運功方式寫在 `docs/catalog/玩家圖鑑_招式.md`。
2. 法術、咒術列出施展指令（cast／conjure）。
3. 內功、劍術等基本技能右欄顯示「基本技能」，不再顯示「多派」；技能分頁另有「基本技能」分類。
4. 左手刀法、單手槍法、斧術、杖法、雙手斧術、雙手槍法、雙握杖法、讀書識字、經脈穴道之學、偷襲暗算技倆、
   古文造詣、五行陰陽之學都算基本技能。
5. 技能歸屬寫在 `玩家圖鑑_技能.md` 的「歸屬」欄：善想禪要為和尚專屬、竹上經心法為龍圖丹派、殺手本能為盜賊專屬。
6. 武功說明改用技能檔裡給玩家看的簡介（`art_desc`）。

## 十、改用遊戲說明檔（使用者指示，2026-10-24）

- 技能細節不寫計算公式，照遊戲說明檔（`mudlib/docs/help/`）的「◎ 名稱（id）」段落顯示：技能種類、學習條件、
  任務起始、特殊能力、能力提昇，另附門派與傳授的連結。以傲梅暗劍訣的說明為範本。
- 有說明檔段落的技能，不再顯示自動讀出的招式、精氣神與屬性欄位，也不顯示法術表；上一節第 1 點的
  `玩家圖鑑_招式.md` 已刪除。
- 沒有說明檔段落的技能（基本技能等）照舊用 `玩家圖鑑_技能.md`、`玩家圖鑑_法術.md`。
