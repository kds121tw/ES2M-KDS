# 玩家圖鑑：門派資料

玩家版天朝圖鑑（`web/codex.html`）的「門派」分頁讀這份表格產生，規劃見 `docs/PLAYER_CODEX_PLAN.md`。

- 只有「師父」欄的 NPC 被放在玩家走得到的房間時，這個門派才會出現在圖鑑上。
- 門下武功由圖鑑程式從師父的傳授清單自動整理，不用寫在這裡。
- 入門條件與簡介是給玩家看的文字：不寫等級數字、不寫指令名稱（`CLAUDE.md` 的遊戲內文字規則）。
- 新增門派或修改文字，直接改下表；下次更新主機時圖鑑會自動重新產生。
