# 玩家圖鑑：法術與咒術

玩家版天朝圖鑑（`web/codex.html`）的「技能」分頁讀這份表格，在法術、咒術類技能底下列出
每道法術的學會等級、耗神、效果與傷害（使用者指示，2026-10-23）。規劃見 `docs/PLAYER_CODEX_PLAN.md`。

- **不寫經驗值（累積點數）的計算公式**；施法得到的技能點數也不寫。
- 「指令」寫施展方式（spells 類用 cast、magic 類用 conjure；使用者指示，2026-10-24，圖鑑可以寫指令）。
- 「學會」寫該技能練到幾級才能施展，0 表示一學會就能用。
- 「傷害」的百分比以**咒文強度**為準（天師道法四系）。咒文強度與命中率公開（使用者指示，2026-10-23），
  圖鑑在法術表下方顯示：
  - 咒文強度 = 慧根² ÷ 10 + 施咒當時的神 ÷ 32 + random(慧根)；基本咒術 100 級起再乘 (50 + 咒術等級)%。
  - 命中率 = 50% + (咒文技巧 − 對方抗性) × 2%，限 5～95%；咒文技巧 = 咒術有效等級 + 咒文能力。
  - 公式改版時（`daemon/skill/taoism-spells.c` 的 `spell_strength()`、`spell_hits()`），同步改 `tools/codex_player_template.html` 的說明。
- 法術名稱欄寫「（共通）」的列，是這項技能所有法術共通的特性。
- 內容依各技能檔的程式整理（2026-10-23）；技能改版時請一起更新這份表格。
