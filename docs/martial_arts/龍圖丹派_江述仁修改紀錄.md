## 實作方式與自訂台詞

- 學習用原版 `acquire <技能> from jiang`；一次補到經驗值 50（含人物等級加成後超過 50 時壓回 50）。
- 不是龍圖丹派弟子：「你不是龍圖丹派弟子，我不能教你<技能名>。」（2026-10-28）
- 竹上經心法根基不足：「你的根基尚淺，恐怕無法瞭解竹上經心法的修練方式。」（2026-10-28）
- 檢查順序：會不會這個技能 → 是不是弟子 → 付過柴火錢 → 竹上經等級 → 是否已學到 50。
- 弟子認定：身上有門派代碼 `alchemist.dragon`（陳維俠收徒時記上），或職業方士且稱號「龍圖丹派弟子」（舊弟子）。
- 沒付柴火錢：「想學？先把柴火錢付了再說。」
- 已學到 50：「我會的都教你了，剩下的自己練去。」
- 傳授：「江述仁將「技能名」的入門要訣傳授給你。」
- 2026-10-22 決定：陳維俠不再教神農之術（「去去去～去找你大師兄，整天無所事事，正好照顧照顧小師弟。」），神農之術、黃白之術改由江述仁教。
