# 和尚：善想禪要（absorption）與打坐（zazen）

狀態：已實作（2026-10-19）：`daemon/skill/absorption.c`、`cmds/std/zazen.c`。來源：使用者指示（2026-10-19）。

## 學習與打坐條件

- 只有和尚能打坐；師父傳授（目前還沒有能收徒、傳授的和尚師父）。
- 戰鬥中、忙碌中、神低於 10 時不能開始。

## 打坐期間（每 tick）

| 項目 | 規則 |
|---|---|
| 消耗神 | 10 − (random(慧根)+1)/8，最少 0 |
| 神上限 | 每 3 tick −1 |
| 技能點數 | (random(慧根)+1) × (random(慧根)+1) + random(慧根)（智力公式換成慧根） |
| 禪定修養 | 每 2 tick +(random(慧根)+1)/6 |
| 心經 | 開始後第 2 tick 起，每 2 tick 在自己畫面顯示一句般若波羅蜜多心經（24 句循環，旁人看不到） |
| 出定 | 神低於 10 自動出定；也可隨時停下 |

## 屬性

- 每升到 5 的倍數級，照原規則有機會增加慧根；**100 級改為固定慧根 +3**，這一級不再擲機率。
- 原本每升一級給 等級 × 30 的禪定修養與佛學修為，維持不變（和打坐的禪定修養兩邊都給，使用者定案）。

## 敘述

| 時機 | 敘述 |
|---|---|
| 開始 | $N盤膝而坐﹐雙手結印輕置膝上﹐垂目斂息﹐漸漸入定。 |
| 心經 | （心經一句，只有自己看到） |
| 自行停下 | $N緩緩吐出一口長氣﹐慢慢張開雙眼﹐眉宇之間一片澄明。 |
| 神不足出定 | $N只覺心神漸感疲憊﹐再也守不住定境﹐於是緩緩收攝心念﹐慢慢張開雙眼。 |
| 100 級 | 靜坐之中﹐你忽覺萬念俱寂﹐心如明鏡不染纖塵﹐一念不生而萬法自現──善想禪要已臻圓融之境。 |
| 不是和尚 | 你並非佛門弟子﹐無從參習善想禪要。 |
| 還沒學 | 你尚未得授善想禪要的法門。 |
| 戰鬥中 | 刀光劍影之中﹐如何靜得下心來打坐？ |
| 神不足 | 你心神太過疲憊﹐一時無法入定。 |
