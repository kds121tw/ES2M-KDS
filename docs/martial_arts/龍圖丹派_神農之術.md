## 一、基本資料

| 項目 | 內容 |
|---|---|
| 名稱 | 丹道【神農之術】 |
| 技能 ID | alchemy-medication |
| 技能類型 | 法術（照原版） |
| 所屬 | 龍圖丹派（方士 alchemist） |
| 學習條件 | **2026-10-22 修改**：付過柴火錢（五兩黃金）的方士向江述仁（`d/qiaoyin/npc/jiang_hsuren.c`）學，最多學到經驗值 50。陳維俠不再教，弟子來學時說：「去去去～去找你大師兄，整天無所事事，正好照顧照顧小師弟。」 |

## 二、封印（七色印）

### 2.1 印的種類

| 編號 | 規則 |
|---|---|
| S-01 | 照原版七色印：青、白、赤、紫、黃、灰、皂（2026-10-15 修正，取代交接文件第十四章「只保留青印、紫印」） |
| S-02 | 每種印都有「封印」與「解印」兩個法術，共十四個 |
| S-03 | 對象只限青銅丹鼎 |
| S-04 | 七色印的規則完全相同（各封各解、消耗、成功率、經驗），只有顏色不同 |

| 印 | 封印指令 | 解印指令 | 說明 |
|---|---|---|---|
| 青印 | `conjure green seal on reactor` | `conjure green dispel on reactor` | 以青印來封住／解開青銅丹鼎 |
| 白印 | `conjure white seal on reactor` | `conjure white dispel on reactor` | 以白印來封住／解開青銅丹鼎 |
| 赤印 | `conjure red seal on reactor` | `conjure red dispel on reactor` | 以赤印來封住／解開青銅丹鼎 |
| 紫印 | `conjure purple seal on reactor` | `conjure purple dispel on reactor` | 以紫印來封住／解開青銅丹鼎 |
| 黃印 | `conjure yellow seal on reactor` | `conjure yellow dispel on reactor` | 以黃印來封住／解開青銅丹鼎 |
| 灰印 | `conjure gray seal on reactor` | `conjure gray dispel on reactor` | 以灰印來封住／解開青銅丹鼎 |
| 皂印 | `conjure black seal on reactor` | `conjure black dispel on reactor` | 以皂印來封住／解開青銅丹鼎 |

解印法術的中文名稱為「散○印」（例如散青印、散皂印）。

### 2.2 封印的效果

| 編號 | 規則 |
|---|---|
| S-10 | 新買的丹鼎沒有封印，買來就能用 |
| S-11 | 封印是玩家自己想封才封，不是使用丹鼎的必要步驟 |
| S-12 | 丹鼎封印後，**不能放東西進去，也不能把東西拿出來**；解印後恢復 |
| S-13 | 封印與藥方無關：不改變藥方的種類、火候，也不讓藥方變質 |
| S-14 | 封住的丹鼎可以放進丹爐，裡面的藥方**照常加熱**，超過焦化上限一樣會燒焦 |
| S-15 | 丹鼎本身照常可以搬動（拿起、丟下、放進或取出丹爐） |
| S-16 | 施法目標只在身上和地上找；丹鼎放在丹爐裡時不能施印，要先取出（接受原版施法規則） |
| S-17 | 外觀只顯示「有封印」，不顯示顏色；要解印須自己記得或嘗試 |

### 2.3 各色印的關係

| 編號 | 規則 |
|---|---|
| S-20 | 各封各解：什麼顏色封的，只能用同色的散印解（例如青印封的只能用散青印解） |
| S-21 | 七種印沒有高低之分 |
| S-22 | 任何人都能解別人封的丹鼎，只要用對顏色、施法成功 |

### 2.4 消耗與成功率（封、解相同）

| 編號 | 規則 |
|---|---|
| S-30 | 每次施法固定消耗 **15 點神**；失敗一樣扣 |
| S-31 | 神不足 15 時不能施法，不扣神、不給經驗 |
| S-32 | 成功率＝（靈性 ＋ 悟性 × 2 ＋ 神農之術等級 ＋ 10）÷ 100，**最高 95%**，不設下限 |
| S-33 | 以下情況**照扣神、一律算失敗**（給失敗經驗）：對已封印的丹鼎再施封印（不論顏色）、用錯顏色解印、對沒有封印的丹鼎解印 |

成功率範例：

| 靈性 | 悟性 | 神農之術 | 計算 | 成功率 |
|---:|---:|---:|---|---:|
| 15 | 15 | 15（剛學成） | 15＋30＋15＋10＝70 | 70% |
| 20 | 20 | 30 | 20＋40＋30＋10＝100 | 95%（上限） |
| 17 | 13 | 0（未學成） | 17＋26＋0＋10＝53 | 53% |

【實作注意】技能等級用原生等級 `query_skill("alchemy-medication", 1)`；未學成時為 0。屬性以 `query_attr()` 取值，對照如下：

| 中文 | 英文 | 中文 | 英文 |
|---|---|---|---|
| 膂力 | str | 定力 | cps |
| 膽識 | cor | 機敏 | dex |
| 悟性 | int | 根骨 | con |
| 靈性 | spi | 慧根 | wis |

## 三、技能提升

| 編號 | 規則 |
|---|---|
| U-01 | 向江述仁學，最多只能學到**經驗值 50**（2026-10-22 修改：原為向師父陳維俠學） |
| U-02 | 之後只能靠施展封印、解印提升 |
| U-03 | 施法成功（封印、解印相同）：獲得 **（靈性 ＋ random(悟性 × 5)）× 2** 點經驗 |
| U-04 | 施法失敗（含 S-33 各情況）：獲得 **random(靈性 ＋ 悟性)** 點經驗 |
| U-05 | 神不足而無法施法：不給經驗 |
| U-06 | 0～14 級不會出現：經驗累積到學成門檻後，下次 `gain` 直接學成 15 級 |
| U-07 | 學成門檻沿用系統預設：15² × 100 ＝ 22,500 點 |
| U-08 | 學成時顯示：「你因為長期使用丹道【神農之術】，所以你對這個法術已經逐漸熟悉。」 |
| U-09 | 學成之後照一般技能規則升級（見 3.1） |
| U-10 | 每次施法增加**丹道修養**（方士職業分數 `alchemy`）：成功 ＋（1 ＋ random(神農之術等級) ÷ 2，無條件捨去），失敗固定 ＋1；神不足無法施法時不加（2026-10-22 修改，原為成功 ＋（1 ＋ random(等級)）） |
| U-11 | **法術修為**（`magic`）只拿系統規則 A，不另外給（2026-10-22 修改：取消原本「31 級起每升一級（sk − 30）² × 10」） |
| U-12 | 系統規則（2026-10-16 由 GitHub 加入，10-18 同步）：<br>A. `conjure` 施法成功時，法術修為、丹道修養各 ＋ random(靈性 ÷ 6) ＋ 1（`cmds/std/conjure.c`）。U-10 的丹道修養另外照給。<br>B. 升到第 n 級時給 n × 10 **法術道行**（`magic mastery`，`feature/char/skill.c`），不另外給。<br>【待修正】規則 A 目前以「指令有沒有執行完」判斷成功，施法失敗也會加分；使用者決定改成真的施法成功才加分（改 `conjure.c`，所有職業法術都適用，2026-10-22） |
| U-13 | 施法時同時累積**基本法術**（`magic`）經驗（2026-10-24，使用者指示 #12）：照茅山法術的基本法術公式，層級固定 1：（random(靈性)＋1）×（random(靈性)＋1）＋random(靈性)。施法失敗（會扣神的失敗）時取 1/3，無條件捨去，最少 1；直接拒絕、不扣神的情況不給。以 `improve_skill_exact` 給，不吃人物等級加成；只給玩家 |

【實作注意】U-10 在 0 級時避開 random(0)：0 級成功固定 ＋1。

【實作注意】`random(n)` 為 0 到 n−1。範例：靈性 17、悟性 13 → 成功得 34～162 點（平均約 98），失敗得 0～29 點。

### 3.1 各等級累積經驗（系統預設門檻）

升到第 N 級所需累積經驗＝N² × 基數（`feature/char/skill.c`）。

| 等級區間 | 基數 | 例 |
|---|---:|---|
| 15（學成） | 100 | 22,500 |
| 16～60 | 100 | 30 級 90,000；60 級 360,000 |
| 61～90 | 125 | 90 級 1,012,500 |
| 91～120 | 150 | 120 級 2,160,000 |
| 121～160 | 175 | 160 級 4,480,000 |
| 161～180 | 200 | 180 級 6,480,000 |
| 181～200 | 250 | 200 級 10,000,000 |

以靈性 17、悟性 13 估算：學成約需成功施印 230 次；練滿 200 級約需成功施印 10 萬次。

## 五、玩家訊息

自己看到的「你」依性別顯示「你／妳」。「青印」依實際施展的法術換成對應的印名（白印、散白印、赤印……散皂印）。

印名上色（使用者定案，2026-10-24）：只有印名上色，句子其他文字不上色；散印比同色的印暗一階。

| 印 | 印名顏色 | 散印顏色 |
|---|---|---|
| 青印 | HIC 亮青 | CYN 青 |
| 白印 | HIW 亮白 | WHT 白 |
| 赤印 | HIR 亮紅 | RED 紅 |
| 紫印 | HIM 亮紫紅 | MAG 紫紅 |
| 黃印 | HIY 亮黃 | YEL 黃 |
| 灰印 | WHT 白 | HIK 灰 |
| 皂印 | HIK 灰 | HIK 灰（沒有更暗、zMUD 也看得到的顏色） |

| 情境 | 訊息 |
|---|---|
| 施法（自己） | 你用手在青銅丹鼎上虛畫了一個「青印」，口中念念有詞地祝禱著。 |
| 施法（旁人） | $N用手在青銅丹鼎上虛畫了一個「青印」，口中念念有詞地祝禱著。 |
| 施法光芒（成功時） | 青銅丹鼎泛起一陣光芒，然後漸漸褪去 .... |
| 封印成功 | 你的青印效力已經成功的被青銅丹鼎吸收了！ |
| 解印成功 | 你的散青印效力已經成功地解開青銅丹鼎上的封印了！ |
| 施法失敗 | 你用手在青銅丹鼎上虛畫了一個「青印」，口中念念有詞地祝禱著。<br>你的法術失敗了。 |
| 神不足 | 你的「神」不足以施展這個法術。 |
| 東西放不進封住的丹鼎 | 你的%N放不進青銅丹鼎。（%N＝要放的物品名稱） |
| 從封住的丹鼎拿東西 | 不顯示原因，只顯示 Ok. |
| 外觀（look 描述末尾） | 鼎口封著一道符印。 |

封印成功、解印成功、施法光芒三句取自原版實況文字。
