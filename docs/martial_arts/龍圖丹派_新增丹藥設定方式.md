# 龍圖丹派｜新增丹藥設定方式

**建立日期：2026-10-15（煉丹與 HERBROOM 結案時；同日依 R1～R9 更新）**
**依據：`docs/martial_arts/龍圖丹派_煉丹流程.md`（規則本體）、龍圖煉丹與藥鋪實作交接（2026-10-15，本機紀錄，未收入 docs）**


煉丹與 HERBROOM 已於 2026-10-15 結案。之後新增丹藥，沿用 `docs/martial_arts/龍圖丹派_煉丹流程.md` 第二～八章的規則，只要補齊下列資料與檔案即可，不需改動系統程式。

## 一、每種新丹藥要由使用者決定的資料

| # | 資料 | 寫在哪裡 |
|---|---|---|
| N-01 | 中文名稱、英文 ID、檔名、內部代碼（例如 black） | 成品檔、藥方檔、`heat_recipes.c`、`herb_catalog.c` |
| N-02 | 讀書識字、神農之術門檻 | 成品檔 `requirement` |
| N-03 | 成品價值（決定成丹售價 ×10、收購價 ×5） | 成品檔 `base_value` |
| N-04 | 一份藥方價值 | 成品檔 `mixture_value` 與藥方檔 `local_value()`（兩處必須相同） |
| N-05 | 火力區間（kW）、熟成熱量、焦化上限、加熱倍率分段 | `heat_recipes.c` 一列，並同步配方檔 `local_recipe()`、`produce_param` |
| N-08 | 配方每份重量（預設 130；大還丹 8,000） | 預設用 `heat_b.h` 的 `MIXTURE_WEIGHT`；特例在配方檔 `configure()` 另設 |
| N-06 | 服用效果、肚子需空出量 | 成品檔 |
| N-07 | 在 herblist 中的排列位置 | `herb_catalog.c` 的 `keys` 順序 |
| N-09 | 丹藥階級（一階最高、三階最低；2026-10-23 起） | 成品檔 `set("pill_grade", 階)`，寫在 `requirement` 下一行 |

量詞固定「粒」、每粒重 5、`inherit COMBINED_ITEM`、配方每份重 130（沿用 `docs/martial_arts/龍圖丹派_煉丹流程.md` 第二、四章）。
自己看到的訊息（例如吞不下）一律用 `gender_self(me)` 顯示「你／妳」；旁人訊息用 `message_vision("$N...")`。

## 二、要新增或修改的檔案（路徑相對於 Standalone mudlib）

| 步驟 | 檔案 | 動作 |
|---|---|---|
| 1 | `obj/medication/alchemist/<檔名>.c` | 新增成品檔（照現有八種的格式） |
| 2 | `obj/medication/alchemist/mixture_<代碼>pill.c` | 新增配方檔（複製現有配方檔，改 `local_recipe()`、`local_value()`、`configure("<代碼>")`、`produce_param`） |
| 3 | `daemon/misc/heat_recipes.c` | 加一列火候資料與成品路徑 |
| 4 | `daemon/misc/herb_catalog.c` | `keys` 加代碼（位置＝herblist 順序）、`product_file` 加對應檔名；一次不是賣五份時改 `recipe_count()` |
| 5 | 專案文件 | 新增 `docs/martial_arts/龍圖丹派_丹藥_名稱.md`（照現有各丹格式），並更新 `docs/martial_arts/龍圖丹派_煉丹流程.md` 各表 |
| 6 | 測試 | 先在隔離副本跑 HEAT B 回歸、藥鋪測試、完整煉丹流程，全部通過才寫入 Standalone |

**NPC 販售（2026-10-23 起）**：販售丹藥的 NPC 改繼承 `obj/alchemist/pill_vendor.c`（取代 `F_VENDOR`），售價依 `pill_grade` 調整，目前二階 ×3、其他照成品價值；要改倍數只改該檔的 `GRADE_MARKUP`。新丹藥只要標好階級，NPC 價格自動套用。藥鋪櫃台價格（×10）不受影響。

代碼規則：配方檔名一定是 `mixture_` ＋ 代碼 ＋ `pill`，`heat_recipes.c` 與 `herb_catalog.c` 用同一個代碼。
