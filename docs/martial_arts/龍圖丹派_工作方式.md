# 龍圖丹派｜工作方式（開新對話用）

**建立日期：2026-10-24**
**用途：每做一件龍圖的事就開一個新對話。照本檔設定與開場，新對話不用重新交代背景。**

---

## 一、原則

| # | 原則 |
|---|---|
| W-01 | 一個主題一個對話：一件事做完、PR 合併後，就開新對話做下一件 |
| W-02 | 同一時間只開一個龍圖的對話，避免兩個對話同時寫進度表而互相蓋掉 |
| W-03 | 設計文件一律放 `docs/martial_arts/`，跟程式一起提交、一起開 PR（見 `CLAUDE.md`） |
| W-04 | 未經使用者確認的細節標「待核對」或「尚未決定」；已確認規格不得自行修改 |

---

## 二、開新對話時的設定

| 項目 | 設定 | 原因 |
|---|---|---|
| 程式碼來源 | `wolfer168/es2-webmud` | 對話可以直接推分支、開 PR。接 `windstory1017/es2-webmud` 時，因為兩個 repo 同名不能同時接，PR 只能由使用者手動開 |
| 電腦資料夾 | `I:\ES2_Standalone`、`I:\Es2 AI資訊` | 單機版程式與本機紀錄；`I:\es2-self` 是舊參考資料，不用接 |
| 模型 | 照規則做的事（開 PR、改數值、改說明檔）用一般模型；要追查原因或動到系統的設計再換較強的模型 | 依使用者帳號實際可用的選項為準 |

## 四、每件事的固定流程

| 步驟 | 內容 |
|---|---|
| 1 | 讀相關設計文件；逐題問清楚，一次問一題 |
| 2 | 確認後，在 GitHub 從最新 main 開工作分支，改程式與 `docs/` 設計文件 |
| 3 | 單機版：先確認要改的檔案與 GitHub main 相同；寫入前備份到 `I:\Es2 AI資訊\claude\alchemist.dragon\備份\`；寫入後讀回逐位元組核對 |
| 4 | 是否測試由使用者決定；沒測就在 PR 與紀錄寫明「未編譯、未測試」 |
| 5 | 開 PR（標題、說明用繁體中文白話），使用者確認後合併 |
| 6 | 在進度表加一筆紀錄 |

### 進度表 `進度與待決事項.md` 的寫法

| # | 規則 |
|---|---|
| L-01 | 寫入前一定先從電腦讀取**目前的版本**，在最後加一列，不可用對話裡留存的舊副本覆蓋 |
| L-02 | 寫入時帶上讀取當下的檔案修改時間（`expectedMtimeMs`），檔案若已被別的對話改過就會拒絕寫入，重新讀取再加 |
| L-03 | 寫入後再讀回確認 |
