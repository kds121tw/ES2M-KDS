# 天師道法【紫薇心經】（chivi sutra）

狀態：技能檔已製作（2026-10-27）：`daemon/skill/chivi_sutra.c`。學習方式（解謎、師父）尚未製作。
來源：使用者指示（2026-10-27）。

## 基本資料

- 技能種類：法術（magic），以 `conjure` 施展；先 `enable magic with chivi sutra`。
- 歸屬：道士共通，解謎習得（見 `門派武功對照表.md`）。
- 能力提昇：無。

## 法術

| 法術 | 指令 | 效果 | 消耗 |
|---|---|---|---|
| 禦火術 | `conjure fire defence` | 短時間提高對火系法術的防禦 | 神 10 |
| 禦風術 | `conjure storm defence` | 短時間提高對風系法術的防禦 | 神 10 |
| 禦冰術 | `conjure freeze defence` | 短時間提高對冰系法術的防禦 | 神 10 |
| 禦雷術 | `conjure thunder defence` | 短時間提高對雷系法術的防禦 | 神 10 |
| 逆運心經 | `conjure dispel` | 強行逆運紫薇心經，把效果消除 | 神 5 |

- 效果 = 紫薇心經等級 + random(靈性)；持續時間 = 紫薇心經等級 ÷ 3 個 tick（一個 tick 兩秒，最少 1）。
- 防禦加在 `apply/armor_vs_fire`、`armor_vs_wind`、`armor_vs_ice`、`armor_vs_lightning`，
  與天師四系施咒時讀的抗性相同（風抗性每 2 點才減 1 點傷害，這是四破重製既有的規則）。

## 補充規則（Claude 預設，可修改）

- 同一系的禦術生效中不能重複施展；四系可以同時存在。
- dispel 一次消除身上所有禦術；身上沒有禦術時不消耗神。
- 到期、被消除時各系的光暈會自行消散，不留舊效果。
- 施展不給技能點數（設計沒有提到）；之後若要練，再補公式。

## 敘述

顏色同天師道法四系施咒：火紅、風紫、冰白、雷黃；施法整句都用該色。

| 法術 | 施法敘述 |
|---|---|
| 禦火術 | $N默誦紫薇心經﹐周身泛起一圈赤紅光暈﹐祭起「禦火術」﹐四周灼人的熱氣漸漸退開。 |
| 禦風術 | $N默誦紫薇心經﹐周身泛起一圈紫色光暈﹐祭起「禦風術」﹐衣袂隨之垂落﹐週遭風勢到了身前便繞道而行。 |
| 禦冰術 | $N默誦紫薇心經﹐周身泛起一圈素白光暈﹐祭起「禦冰術」﹐侵人的寒意遇上光暈便如殘雪消融。 |
| 禦雷術 | $N默誦紫薇心經﹐周身泛起一圈金黃光暈﹐祭起「禦雷術」﹐光暈之外隱隱有電光游走﹐卻近不得身。 |
| 到期 | 你身上那圈（赤紅／紫色／素白／金黃）光暈漸漸黯淡﹐禦X術的法力已盡。 |
| dispel | $N強行逆運紫薇心經﹐真氣反沖﹐週身的光暈應聲碎散。 |
| 神不足 | 你的心神不足﹐無法施展紫薇心經。 |
| 已生效 | 你身上已經有禦X術的法力了。 |
| 沒有禦術 | 你身上沒有紫薇心經的法力可以消除。 |
