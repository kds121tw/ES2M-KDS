## 一、一句招式的骨架

> **起勢（身形／步法）→ 出手（哪隻手、哪個部位、兵器怎麼動）→ 去向（打向哪裡）**

- 起勢只用一個動作帶過：踏步、矮身、擰腰、側身、縱起、斜跨。
- 出手要說清楚**哪一隻手、哪一隻腳**在做什麼，左右分工是武俠打鬥最有畫面的地方。
- 去向固定落在「$n的$l」（遊戲會換成部位）。
- 一句控制在 25～45 字，用「﹐」切成二到四小段。結尾不加句號（戰鬥訊息會接後文）。

自撰範例：

- $N左足踏前半步﹐右手長劍斜斜一挑﹐劍尖顫處直取$n的$l
- $N身形一矮﹐左掌虛按﹐右拳自肋下穿出﹐搗向$n的$l

## 二、招式名稱放哪裡

招名用「」包起來，常見三種位置，同一套武功要混用，不要每招都同一個句型：

1. **招名在前，當成動作**：「$N一招「〇〇〇〇」﹐……刺向$n的$l」
2. **招名在中，先有起勢**：「$N擰身上步﹐使出「〇〇〇〇」﹐……」
3. **招名接在動作後面點題**：「$N雙掌一合一分﹐正是「〇〇〇〇」﹐……」

**招名的意象要和動作對得上**：叫「鷹」就要有居高撲擊，叫「柳」就要有柔、垂、擺，叫「浪」就要有連綿。
沒有招名的招式，直接寫動作，靠動作本身的意象撐起來。

## 三、動詞要分兵器

| 兵器 | 常用動詞 |
|---|---|
| 劍 | 刺、點、挑、撩、削、抹、圈、絞、斜削、迴鋒、遞出 |
| 刀 | 劈、砍、斫、斬、截、掃、撩、剁、橫削 |
| 鞭 | 抖、甩、捲、纏、砸、掄 |
| 杖、棍 | 點、掃、挑、撐、戳、砸、架 |
| 槍 | 刺、扎、挑、抖、撥 |
| 掌 | 拍、劈、按、推、穿、印、切 |
| 拳 | 搗、錘、衝、砸、撞 |
| 指、爪 | 戳、點、插、扣、抓、拿 |
| 腿 | 踢、踹、掃、勾、蹬 |

同一套武功裡，動詞不要重複超過兩次。

## 四、讓招式活起來的手法

- **虛實與變招**：一手虛晃、一手實擊；招到中途轉向；看似攻上、實則打下。
  例（自撰）：$N左手劍訣虛引﹐右手長劍卻從下路翻起﹐撩向$n的$l
- **速度與力道用四字短語**：快捷無倫、勁力沉雄、去勢奇快、輕靈飄忽、後勁綿長。每句最多一個，不要堆。
- **擬聲**：「刷」「嗤」「呼」「噹」「拍」放在動作前後點一下，例如「呼的一聲」。一套武功裡只放一兩招，太多就吵。
- **方位詞**：斜裏、橫裏、居高臨下、反手、迴身、逕取、直取、下盤、中路。
- **身體部位**（寫攻擊路徑用，不要和 $l 重複）：肩頭、肘底、腕上、腰間、膝彎。

## 四之二、更多手法（第二批文本）

- **左手配合**：劍客出招時另一手常有動作——捏劍訣、劍訣一領、駢指如戟、左掌護胸、袖子一拂。
  例（自撰）：$N左手劍訣一領﹐右手長劍隨勢平推﹐劍鋒貼著$n的$l削去
- **打穴位**：高手點、扎、戳時可寫穴位（肩井、天突、華蓋、曲池、環跳）。穴位寫在攻擊路徑或手法裡，目標仍用「$n的$l」。
- **劍花、刀網**：快劍用「抖出數朵劍花」「劍尖顫處寒星點點」；刀法用「刀光織成一片」。
- **招中蘊招**：一招之中暗藏後著、使到一半已變。適合寫進閃避或招架的對手反應，或特效敘述。
- **連綿不斷**：一招收勢即是下一招起勢，如柔絲不斷——很適合「持續作戰」型的武功（例如封山派）。
- **硬碰與巧卸**：兵刃相交寫聲音與反震（虎口發麻、橫移半步）；巧卸寫貼、粘、帶、引。
- **距離與時機**：「劍尖離咽喉不過寸許」「刀未至，勁風已先撲面」，用距離寫出快與險。

## 四之三、各家風格（依門派氣質挑選）

| 風格來源 | 特點 | 適合 |
|---|---|---|
| 金庸 | 招名典雅、動作有套路；左右手、腳的分工交代清楚；招名常借典故（白鶴亮翅、蒼鷹搏兔一類意象） | 正派、名門劍法（封山、冷梅、天師） |
| 梁羽生 | 招名多四字古典意象；常寫穴位與「劍訣一領，青光疾閃」；節奏緊湊，「一招緊似一招」 | 劍法、點穴類武功 |
| 古龍 | 少寫招名，重速度與結果；短句、留白；用距離（差一寸）與心理張力寫險 | 快劍、殺手型、特效敘述（一擊必殺） |
| 黃易 | 重刀氣、勁氣、意境；擬聲常獨立成句「噹！」；刀勢一刀重似一刀；寫氣機牽引 | 霸道刀法、內功特效（虎刀門、天邪） |
| 臥龍生 | 招名直白有力；常寫封擋、借力打力、劍路奇特 | 一般門派、NPC 武功 |

遊戲裡一句招式很短，主體仍用「起勢→出手→去向」；各家風格只取用字與節奏，不要整段移植。

## 五、閃避與招架

- 閃避：側身、矮身、後仰、擰身、斜跨一步、縱起、倒退半步；結果用「撲了個空」「落了個空」「擦身而過」。
- 招架：橫劍封住、圈轉兵刃卸力、手肘搭住來腕、以掌緣切開。招架要寫出**怎麼化解**，不要只寫「擋住了」。
- 閃避句以「$n」開頭，寫完閃的動作就收，不加句號。

## 五之二、練成敘述

- 每套武功設計時，一併規劃「練成敘述」（從零學成那一刻顯示的一句話），寫進該武功的設計文件。
- 寫法：以「你」開頭，點出武功名稱，再用一個意象收住這套武功的氣質，例如
  「你終於練成了清河映星劍﹐劍光流轉之間﹐隱隱已有星河雷雨之勢。」
- 步法、身法偏「參透方位」「身形已能…」；劍刀拳掌偏「劍光」「刀勢」「拳意」；內功偏「真氣」「丹田」「周天」。
- 不提等級數字、不提指令；結尾用「。」。

## 六、要避免的

- 現代詞彙與語氣（「超快」「瞬移」「暴擊」「技能」）。
- 一句裡兩個以上比喻；形容詞堆疊。
- 每招都「如〇〇般」同一句型。
- 等級數字與指令（見 CLAUDE.md）。
- 直接搬用小說的原句或招名（招名要自創，可以借用同類意象）。

## 七、檢查清單

1. 有沒有起勢、出手、去向三段？
2. 左右手／腳的分工清楚嗎？
3. 動詞符合兵器嗎？同套武功有沒有重複？
4. 招名意象和動作對得上嗎？句型有沒有輪替？
5. 長度 25～45 字、用「﹐」切段、結尾沒有句號？
