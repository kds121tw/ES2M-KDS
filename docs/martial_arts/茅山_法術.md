# 茅山派法術

狀態：茅山法術已實作（2026-10-21）：`daemon/skill/mao-shan_magic.c`；師父 杜風凌、歐陽無極。來源：使用者指示（2026-10-21）。

## 名詞

- **茅山派道士**指的是三個門派：幻霧觀（`taoist.huanwu`）、隱風觀（`taoist.wind`）、靈雲觀（`taoist.lingyun`）。
- 三個門派各有專長的技能，也有共同可學的技能。
- **共通**技能：三個門派都可以跟師父學習，或解謎習得。

## 一、茅山法術（mao-shan magic）── 茅山共通

- 技能種類：法術（magic）。學習條件：拜師後。
- 練成 1 級；每級精 +1～2、氣 +1～2、神 +3。
- 特殊能力：

| 法術 | 效果 | 消耗 |
|---|---|---|
| blank | 把其他的符紙變回普通的（空白符紙） | 神 5 |
| yin | 把普通的符紙變成少陰符 | 神 10 |
| yang | 把普通的符紙變成正陽符 | 神 10 |
| nature | 把普通的符紙變成先天符 | 神 10 |
| remedy | 消耗先天符，回復施法者體力；技能過低時沒有效果 | 先天符 |
| vision | 消耗先天符，提昇施法者的警覺性，並賦予陰陽眼 | 先天符 |

- 已有的道具：`custom/item/scroll/` 的空白符紙（blank）、少陰符（yin）、正陽符（yang）、先天符（nature）；
  空白符紙在喬陰縣雜貨鋪販賣。

## 使用者回覆（2026-10-21）

1. 轉換符紙：每施一次轉換一張。
2. remedy：回復量 茅山法術等級/4（等級低於 4 時算出來是 0，自然沒有效果）。
3. vision：警覺性 +等級/2，持續 等級/5 個 tick；陰陽眼可看見鬼魂（用遊戲原有的 `vision_of_ghost`）。
4. 點數：比照天師道法，公式見下。
5. 師父：幻霧觀 杜風凌（`custom/legacy_npc/du_feng_ling.c`）、隱風觀 歐陽無極（`custom/legacy_npc/ou_yan_wu_ji_2.c`）；
   靈雲觀觀主 林正陽（Lin zheng yang）尚未製作。
6. 敘述：簡要即可。

## 定案（2026-10-21）

- 點數（每次施展成功，各自擲骰）：
  - 基本法術：((random(靈性)+1) × (random(靈性)+1) + random(靈性)) × (random(層級)+1)
  - 茅山法術：((random(悟性)+1) × (random(靈性)+1) + random(靈性)) × (random(層級)+1)
  - 層級：blank 1；yin、yang、nature 2；remedy、vision 3。
- 法術修為 random(靈性/6)+1：conjure 指令本來就會給（2026-10-16 定案），不重複加。
- 丹道修養：只有施展丹道【神農之術】時 conjure 才另外給，其他法術（含茅山法術）不給（使用者指示，2026-10-21）。
- remedy：精、氣、神都回復，各自擲 1～等級/4；等級低於 4 時沒有效果（先天符照樣用掉）。
- vision：警覺性 +等級/2、陰陽眼，持續 等級/5 個 tick（最少 1）；效果中不能重複施展。
- 學習條件：茅山派（幻霧觀、隱風觀、靈雲觀）弟子。
- 師父：杜風凌（幻霧觀，尚未放入地圖）、歐陽無極（隱風觀，在 `/d/kangping/inn`）。
  平民才能拜師，拜師後成為道士，稱號「幻霧觀弟子」「隱風觀弟子」；傳授茅山法術與基本法術。
  隱風觀不收夜叉、刑天、厭火、黑齒（使用者指示，2026-10-21）：「你與本觀的道法無緣﹐還是另尋去處吧。」
- 靈雲觀觀主林正陽：之後再做。

## 敘述（簡要）

| 時機 | 敘述 |
|---|---|
| blank | $N手掐法訣在符紙上一抹﹐符上的硃砂字跡隨即褪去。 |
| yin／yang／nature | $N提筆蘸了硃砂在符紙上畫了幾筆﹐一張（符名）便成了。 |
| remedy | $N點燃一張先天符﹐吸入那縷青煙後精神好了許多。 |
| remedy 技能太低 | $N點燃一張先天符﹐符紙化作一縷青煙﹐卻什麼事也沒發生。 |
| vision | $N將先天符貼在眉心﹐雙眼泛起一層淡淡的幽光。 |
| vision 結束 | 你眼前那層幽光漸漸淡去。 |
| 沒有符紙 | 你身上沒有空白符紙。／你身上沒有先天符。／你身上沒有可以化回空白的符紙。 |
| 神不足 | 你的心神不足﹐無法施展茅山法術。 |
| 杜風凌收徒 | 杜風凌淡淡地點了點頭：好﹐從今以後你便是幻霧觀的弟子。／杜風凌說道：旁人瞧不起的小把戲﹐用得好了一樣能成大事。 |
| 歐陽無極收徒 | 歐陽無極撫了撫長鬚：好﹐從今天起你便是隱風觀的弟子了。／歐陽無極說道：風無常勢﹐修道的人心思也要靈活些。 |
