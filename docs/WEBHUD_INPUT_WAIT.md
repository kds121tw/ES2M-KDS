# 網頁背景查詢：等待輸入時暫停（2026-10-24）

> 使用者回報：魂飛魄散後重選種族時畫面一直跳「請重新輸入」；巫師用 edit 改程式時也會受干擾。

## 原因

網頁每隔幾秒在背景送 `webhud` 查詢狀態（血量、房間、身上物品）。遊戲在「等玩家回答」的時候
（選單、Yes/No、寫文章、翻頁、巫師 `edit`），這行查詢會被當成玩家的回答：
選種族回「請重新輸入」、Yes/No 重印提問，巫師 `edit` 甚至可能把 `webhud` 寫進檔案。

## 做法

| 步驟 | 位置 | 內容 |
|---|---|---|
| 認出網頁玩家 | `cmds/usr/webhud.c` | 收到 webhud 就在角色與連線物件記下 `webhud/client` |
| 暫停 | `feature/user/input.c` 的 `input_prompt()` | 網頁玩家進入任何等待輸入時送 `@@WEBHUD|INPUT` |
| 暫停（編輯器） | `adm/simul_efun/webhud.c` 的 `ed()` | 巫師 `edit` 進入編輯器時送 `@@WEBHUD|INPUT` |
| 暫停（重選種族） | `adm/daemons/logind.c` 的 `show_race_menu()` | 這裡的輸入不經過 `input_prompt()`，另外送 |
| 恢復 | `feature/char/message.c` 的 `write_prompt()` | 回到指令提示「>」時送 `@@WEBHUD|READY` |
| 網頁 | `web/app.js` | 收到 INPUT 停止背景查詢，收到 READY 恢復；萬一沒收到 READY，看到指令提示「>」也恢復 |

- 記號只送給網頁玩家；zMUD／telnet 玩家看不到也不受影響。記號行由網頁過濾，不會顯示在畫面上。
- 另外保留兩道保險：網頁看到選種族、性別、名稱等提示也不送查詢；選種族、取名字收到 `webhud` 時不回錯誤訊息。

## 驗證（Neolith＋瀏覽器實測）

- 網頁上魂飛魄散後，選種族、性別、名稱、確認各停 10 秒以上：沒有「請重新輸入」，每個提問只出現一次。
- 巫師在網頁 `edit` 檔案，編輯中停 12 秒：背景查詢 0 次，存檔內容只有輸入的兩行；離開編輯器後查詢恢復。
- 一般狀態與戰鬥中照常查詢，沒有出現記號。
