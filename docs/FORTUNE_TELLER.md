# 喬陰縣算命先生：算技能天賦（2026-10-23）

> 使用者需求與決定（2026-10-23）。
> 程式：`source/upstream/mudlib/d/qiaoyin/npc/fortune_teller.c`（在 `/d/qiaoyin/tree_tomb` 樹王墳）。
> 天賦就是這項技能在這名玩家身上的上限（`skill_cap/<技能>`，140～200）。

## 流程

1. `ask teller about 算命`：
   ```
   算命先生微笑說道﹕呵呵？這位(尊稱)想算命吧，老夫一見到你就知道是有緣人。
   算命先生說道﹕(尊稱)且不用開口，嗯 ... 想問事業？
   算命先生說道﹕這樣吧，就當作和這位(尊稱)結個緣，一卦只要一兩黃金，如何？
   ```
   尊稱依玩家職業（道長、英雄、仙師……）。第一句後隔 2 tick 說第二句，再隔 1 tick 說第三句（2026-10-23）。
2. `give 1 gold to teller`：
   ```
   算命先生微笑著向你點了點頭，問明了你的生辰八字，拿出一個龜殼和幾枚銅錢，占卜了起來。
   算命先生問道﹕不知(尊稱)要問(inquire)的是哪方面的事業？
   ```
   先出現「你拿出…交給算命先生」，算命先生才開始占卜。
3. `inquire <技能>`（英文代碼或中文名稱都可以）：
   ```
   算命先生將龜殼中的銅錢搖了搖，灑在桌上，然後掐指算了算。
   算命先生告訴你﹕(尊稱)在縱躍閃躲之法上的發展還算不錯，只要肯下苦功，他日當有一番成就。
   ```
   搖銅錢後隔 2 tick 才說批語；批語只有玩家自己看得到。

1 tick 約 2 秒。

## 規則

- 一卦一兩黃金（等值的錢也收，多付不找零）；付一次算一次。少於一兩不收；已付過還沒算又給錢不收。
- 問的技能玩家沒有：「嗯 ... 看來(尊稱)並沒有這項技能。」這一卦還留著，可以改問別的。
- 付錢後離開樹王墳：這一卦作廢，不退錢。
- 付錢後在原地超過 30 tick（約 60 秒）沒問：「(尊稱)既然拿不定主意，看來緣分未到，改日再來吧。」作廢，不退錢。

## 批語（與隱風觀遁甲書「天命」相同）

| 上限 | 批語 |
|---|---|
| 200 | 發展可說是無可限量，舉世無匹！…日後定能成為一代宗師！ |
| 190～199 | 發展委實是非同凡響！…必能練就震動天下的驚人藝業！ |
| 180～189 | 發展非常不一般呀！看來（尊稱）日後定然能以此技笑傲江湖！ |
| 170～179 | 發展相當不錯呀！看來（尊稱）可以憑此技名揚天下！ |
| 160～169 | 發展不錯，若是棄而不練，真是可惜啊。 |
| 150～159 | 發展還算不錯，只要肯下苦功，他日當有一番成就。 |
| 140～149 | 發展一般，雖不能成名，但也可憑此謀生。 |

批語由 `daemon/skill/taoism_of_dunja.c` 的 `fate_words()` 產生，兩邊共用同一份文字。

## 驗證（Neolith 實際載入，2026-10-23）

- ask 算命三句、給一兩銀子被拒、給黃金後開始占卜、重複付錢被拒。
- 問沒有的技能（降龍十八掌）回答沒有、卦金保留；接著問「縱躍閃躲之法」得到批語（上限 160，「發展不錯…」），再 inquire 已無卦可算。
- `inquire literate`（英文代碼）正常；付錢後離開再回來，卦已作廢。
- 付錢後等 62 秒出現「看來緣分未到」，之後 inquire 已無卦可算。
